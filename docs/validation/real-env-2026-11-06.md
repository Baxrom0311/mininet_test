## 4. Kalibratsiya (`lab.benchmarks.real_calibration`, 3 takror, yangi tarmoq har takrorda)

Protokol holati hodisadan keyin qurilmada kuzatiladi (OVS port holati, `show vrrp`,

javobsiz oraliq. `python3 -m lab.calibration real-calibration-2026-11-06.csv`:

| Protokol | Metrika | Model | Real (median) | n | Chegarada |
|---|---|---:|---:|---:|---|
| STP | port_forwarding_s | 30 | **29.7** | 3 | ✓ |
| STP | traffic_gap_s | 30 | 29.6 | 3 | ✓ |
| RSTP | port_forwarding_s | 1 | **0.002** | 3 | ✓ (model pessimistik) |
| VRRP | master_down_s | 3.61 | **3.52** | 3 | ✓ |
| VRRP | traffic_gap_s | 3.61 | 3.48 (3.45–5.02) | 3 | ✓ |
| RIP (update 10) | route_recovery_s | 5 | **7.97** (5.9 / 11.0 / 8.0) | 3 | ✓ (keng tolerans) |
| BGP | session_recovery_s | 2 | **1.23** | 3 | ✓ |
| OSPF (hello 1 / dead 4) | route_update_s | 0 | **1.74** | 2 | **✗** |
| OSPF | traffic_gap_s | 0 | 1.67 | 2 | **✗** |

Xulosalar:
- **STP 2×forward_delay modeli tasdiqlandi** (29.7 s). Oldingi "real ~23 s" qiymati
  emulyatsiyaning 1 soniyalik binlari bo'yicha olingan taxmin edi — noto'g'ri.
- **VRRP Master_Down_Interval** modeli aniq (3.61 vs 3.52 s); end-to-end uzilish shu
  ulanishda qo'shimcha ~0–1.5 s.
- **OSPF**: analitik model SPF'ni darhol deb oladi, real FRR'da carrier-down bilan ham
  ~1.7 s marshrut yo'q (SPF throttle/LSA arrival). Kalibratsiya vositasi OSPF uchun
  override taklif qilmaydi (dizayn bo'yicha) — modelga `ospf_convergence_s` (standart
  ~1.7 s, `hello/dead` va SPF taymerlariga bog'liq) qo'shish kerak.
- **RIP**: real median 8.0 s, model `update/2` = 5 s. 3 namuna kam; FRR update jitter'i
  bilan kutilgan qiymat `update/2` dan katta ko'rinadi — ko'proq takror (≥10) bilan
  qayta o'lchab, keyin modelni o'zgartirish.
- **RSTP** (to'g'ridan-to'g'ri uzilish) va **BGP** (link up) modelda pessimistik.
- 1 OSPF takrori (rep 1) yaroqsiz: hodisagacha ping javobi yo'q edi (tarmoq tayyor
  emas) — CSV'dan chiqarildi; vosita endi bunday takrorni avtomatik rad etadi.

`suggested_scenario_overrides` (faqat ko'rib chiqish uchun, standartlar o'zgartirilmadi):
`stp_convergence_s 29.66`, `vrrp_convergence_s 3.52`, `rip_convergence_s 7.97`,
`bgp_convergence_s 1.23`.
